# Changelog

All notable changes to this project will be documented in this file.

## [Unreleased]

## [0.1.8] - 2026-06-01

### Removed

- PHP 8.1 support (from composer.json)

## [0.1.7] - 2026-06-01

### Added

- PHP 8.4 support
- PHP 8.5 support
- Add Symfony 8.x support

### Removed

- PHP 8.1 support
- `thecodingmachine/safe:^2` support

### Added

- `thecodingmachine/safe:^3` support

### Added

1-12
